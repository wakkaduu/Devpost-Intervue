Mock interviews by voice or writing, with specific AI coaching on every answer. Scope said "pick a category and answer"; this page says exactly what happens.

The journey

Walk through each step

Home. Focal card with current track, Voice/Written toggle, Start practicing. 52 tracks via a searchable picker. Last mode remembered.
  • Empty/error: starting with no track shows an inline error and stays on Home.
  • Check: track and mode visible; mode preselected from last visit.
Answer. One question at a time, read aloud on request, timer, autosaved draft. Voice: live transcript + delivery HUD. Written: text box.
  • Mic denied/unsupported: message + typed fallback; 3 retries; auto-stop at max length.
  • Empty answer blocked, no AI call.
Review. Score 1-10, one thing to work on first, a stronger version, the interviewer's follow-up question, the interviewer's take; delivery: WPM, fillers, tone read.
  • Check: feedback quotes what the user actually said.
  • Failure: clear error + retry; basic-feedback notice if only a fallback provider works.
Results. Average score (one decimal), verdict (Interview-ready / Almost there / Needs work / Not ready yet), AI debrief: patterns, best and weakest answer, fix first.
  • Ended early: only answered questions. Zero answers: "no answers submitted", no score.
History. One point per session, average score over time; filter by track; table view; "since your first session" note with 2+ sessions.
  • No sessions: friendly empty state. No duplicate points on duplicate saves.
  • Guests: browser storage. Signed in: across devices.
